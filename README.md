# 📅 My Calendar (个人日历自动同步订阅源)

本仓库用于在线维护个人日历订阅源的 `.ics` 文件（`todo.ics`），并通过 GitHub Pages 提供静态链接供多端设备进行日历订阅。

## 🔄 系统整体架构

日历数据流向为完全自动化的闭环架构：

```
[ 本地 Obsidian 笔记/任务记录 ]
        │  
        ▼ (通过 Git 同步插件推送)
[ GitHub 私有库 (thiter/testnote) ]
        │  
        ▼ (触发 GitHub Actions 编译流水线)
[ 任务解析脚本 (parse-tasks.js) ] ── (自动过滤/提取/清洗标题/转换格式)
        │  
        ▼ (自动 Force Push 强推生成)
[ GitHub 公开库 (thiter/my-calendar:gh-pages) ] ── 提供 todo.ics 静态链接
        │  
        ▼ (每 5 分钟或按设备设定自动拉取)
[ 各终端日历客户端 (iOS / macOS / Android / Outlook) ]
```

## 📅 Obsidian 任务编写语法规范

任务解析器基于标准的 iCalendar (RFC 5545) 协议开发。在 Obsidian 中记录时，**任务行必须以 `- [ ]` 开头（即未完成状态）**。系统支持以下任务语法：

### 1. 基础任务（单次日程）
* **全天事件（无具体时间）**
  * 语法：`- [ ] 任务内容 🛫 YYYY-MM-DD` 或 `- [ ] 任务内容 📅 YYYY-MM-DD`
  * 示例：`- [ ] 审查 IP Sentinel 系统日志 🛫 2026-06-07`
* **定时事件（具体开始时间）**
  * 语法：在行内任何位置写上 `HH:mm`。日历将自动将其转换为带具体时间的日程（默认时长为 1 小时）。
  * 示例：`- [ ] 🛫 2026-06-07 14:30 甲方架构方案评审会`
* **跨天/多天全天事件**
  * 语法：使用 `➡️ YYYY-MM-DD` 声明截止时间。
  * 示例：`- [ ] 🛫 2026-06-08 ➡️ 2026-06-12 软著申报材料自动化编写`

### 2. 高级周期循环任务 (RRULE)
* **标准周期**：
  * 支持 `🔁 daily` (每天) / `🔁 weekly` (每周) / `🔁 monthly` (每月) / `🔁 yearly` (每年)。
  * 示例：`- [ ] 备份 Obsidian 核心库 📅 2026-06-08 🔁 weekly`
* **每周固定某一天**：
  * 语法：`🔁 weekly:周几`（支持中文：一、二、三...日，或英文：MO, TU...）。
  * 示例：`- [ ] 审核团队周报并提交 📅 2026-06-08 18:00 🔁 weekly:一`
* **每月固定某几天**：
  * 语法：`🔁 monthly:号数`（多天用英文逗号 `,` 分隔）。
  * 示例：`- [ ] 结算云服务器账单 📅 2026-06-01 🔁 monthly:1,15`
* **自定义间隔天数/周数（高阶支持）**：
  * 语法：`🔁 daily:间隔数` 或 `🔁 daily;interval=间隔数`。
  * 示例：`- [ ] 提醒保号发短信看备忘录 📅 2026-07-28 🔁 daily:179`（每隔 179 天提醒一次）

### 3. 优先级置顶展示 (Priority Emojis)
支持 Obsidian Tasks 的 5 种标准优先级 Emoji。解析器会自动识别并**将其置顶展示到日历日程标题的最前面**：
* 🔺 最高优先级 (Highest)
* ⏫ 高优先级 (High)
* 🔼 中优先级 (Medium)
* 🔽 低优先级 (Low)
* ⏬ 最低优先级 (Lowest)

*示例*：`- [ ] 🔺 打印公司凭证 🛫 2026-06-29`
在您的设备日历上显示的标题为：`🔺 打印公司凭证`

## 🛠️ 设备端订阅方法

### Mac (macOS 日历)
1. 打开系统自带的 **日历 App**。
2. 点击顶部菜单栏的 **文件 (File)** -> **新建日历订阅 (New Calendar Subscription)**。
3. 粘贴您的 [订阅链接](#-唯一日历订阅链接)。
4. 在设置窗口中，建议将“自动刷新 (Auto-refresh)”更改为 **每 5 分钟** 或 **每小时**。

### iPhone / iPad (iOS / iPadOS 日历)
1. 打开系统 **设置 (Settings)** -> **日历 (Calendar)** -> **帐户 (Accounts)**。
2. 点击 **添加帐户 (Add Account)** -> 选择最下方的 **其他 (Other)**。
3. 点击 **添加已订阅的日历 (Add Subscribed Calendar)**。
4. 粘贴您的 [订阅链接](#-唯一日历订阅链接) 并保存即可。

## 🔒 安全性与消费控制说明

1. **隐私隔离**：您的核心笔记和未带日期/未带 `📅` `🛫` 标志的日历信息安全地保留在您的私有仓库 `testnote` 中。公开的 `my-calendar` 仅暴露生成的任务标题、MD5 混淆加密的 UID 以及时间数据。
2. **零扣费保护**：本账户的 GitHub Actions 预算及按量付费已被完全限制（已在 `Budgets and alerts` 中设置了 **$0.00 budget** 并开启了 **Stop usage: Yes**）。Actions 在免费的 2,000 分钟用尽后将自动暂停，**绝不会产生任何信用卡扣款**。
3. **智能构建触发优化（防额度浪费）**：在 `testnote` 仓库的 `sync-to-calendar.yml` 工作流中，配置了细粒度的路径限制（`paths` filter）。现在，只有当 `todo/` 或 `obsidian/日历/` 目录发生变动时，或者手动通过 `workflow_dispatch` 触发时，才会执行日历同步流水线。这极大避免了日常非待办笔记修改所导致的不必要 Actions 虚拟资源消耗，解决了短时间内海量构建冲突和通知轰炸的问题。
